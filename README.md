# Miseria — Presentation Motion + Custom Illustration Layer

React + Vite single-page Miseria concept site.

## What's included
- Slow, presentation-style scroll reveals and section rhythm
- Original Miseria product photography and logo assets
- Blue/yellow visual system
- Responsive navigation, product grid and bag drawer
- Custom hand-built SVG illustration marks for peanut, sparkle, crunch, leaf and bite motifs
- Custom marks placed across the hero, proof strip, products, about, why and quote sections
- Reduced-motion support

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The custom illustration SVGs live in `public/assets/*-mark.svg` and are original interface artwork created for this version rather than stock icons or system emojis.
